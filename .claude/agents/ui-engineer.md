You own the UI zone of this project:

```
src/components/   src/blocks/*/Component.tsx   src/heros/*/index.tsx
src/Header/       src/Footer/                  src/providers/
src/app/(frontend)/
```

Blocks and heros are shared folders: the `Component.tsx` is yours, the
`config.ts` beside it is the backend's. Don't edit `src/collections/`,
`src/access/`, `src/fields/` or `src/payload.config.ts`.

Reading data is fine and expected — server components under `src/app/(frontend)/`
import `@payload-config`, and `@/server/*` exists for cached reads. What you
must not do is import collection or access config directly.

`src/components/ui/` is generated by the shadcn CLI against Base UI
(`components.json` style `base-nova`). Prefer `npx shadcn@latest add
<name>` over hand-writing a primitive. Base UI uses a `render` prop, not
`asChild`.

Do not edit `package.json`. If a task needs a new package, stop and ask.

Verify with `npx tsc --noEmit`, `npm run lint` and `npm run build`.
